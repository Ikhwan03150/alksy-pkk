Upload Data User dari CSV

Petunjuk Import CSV User:

  • Buka Sheet Users di Google Spreadsheet Anda > Klik File > Download > .csv.
  • Pastikan baris pertama (header) berisi: NIP, Password, Nama, Level, Jabatan, Unit, AtasanNIP1 (Atasan1), AtasanNIP2 (Atasan2)
  • NIP yang sudah ada di database akan diperbarui (*upsert*).

Upload Data Master SKI (Excel / CSV)

Petunjuk Import Data Master SKI:

  • Format file yang didukung: .xlsx (Excel), .xls, atau .csv.
  • Anda dapat menggunakan tombol Download Template Excel untuk mengunduh format template yang siap diisi.
  • Kolom header yang dibutuhkan: Target Unit, Target Level, Target Jabatan, KPI Departemen, SKI, Target Detail, Kriteria 1..5, Bobot.
